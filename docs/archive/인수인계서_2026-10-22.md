## 0. 작업 규칙 (사용자 선호)
- **대답은 항상 한국어로.** 쉬운 말로, 초보자도 이해하게.
- 코드를 고치면 **테스트를 돌리고** → `quant_system.zip`으로 다시 묶어 → 마지막에 **적용 명령**(아래 3번)을 안내.
- 새 채팅 시작 시: 첨부된 zip을 `/mnt/user-data/outputs/quant_system`에 풀어야 테스트가 동작해요(테스트가 이 경로를 씀).
  `cd /mnt/user-data/outputs && unzip -o /mnt/user-data/uploads/quant_system.zip`
- 테스트: `bash quant_system/tests/run_all.sh 1` ~ `5` (한 번에 5분 제한이라 5번에 나눔). 실패만 출력됨. 87개 파일.
- 휴대폰 화면 직접 확인(캡처 없이도 가능): 작업 공간에 헤드리스 크롬(playwright)이 있음. 테스트 시드 스크립트로 임시 DB를 만들고(`tests/test_home_company.py`·`test_pick30.py`의 tmp 경로만 고정) streamlit을 띄운 뒤 390·360px로 찍기. 크롬은 `--no-proxy-server`, 화면은 안쪽 상자가 스크롤되므로 full_page 대신 세로가 긴 viewport, 인터넷 조회가 막혀 있어 페이지당 45~60초 대기. 서버 종료는 pid 파일로(`pkill -f`는 자기 셸까지 죽임).
- 사용자가 김곰 워치리스트·래빗스탁 화면을 캡처해 오면 "우리가 쓰는 것보다 좋아 보이는 건 다 쓰고 싶다"는 방향. 다만 서술형 AI 해석처럼 규칙으로 못 만드는 건 솔직히 말하고 대안 제시.
- 모든 점수·판정은 **규칙 기반 추정이며 투자 권유가 아님**을 화면에 유지.
