## 3. 계산
### 계산 1 — 몬테카를로(앞으로 1만 번)
- 재료: 그 종목 최근 250거래일 하루 묶음(전일 종가 대비 시가 갭 % · 고가 % · 저가 % · 종가 %) → **블록 부트스트랩**(3~5일 묶음, 추세·변동성 뭉침 유지).
- 하루마다 고가 ≥ 목표 → 익절, 저가 ≤ 손절 → 손절. **같은 날 둘 다면 손절**(보수적) — 그 비율도 따로 표시. 기간 끝까지 결판 안 나면 종가.
- 결과: 목표 먼저 % · 손절 먼저 % · 결판 안 남 %(그때 평균 수익) · 기대값(%/거래) · 표본 일수(n).
- numpy 벡터(1만 × 40일 1초 안). 자료 120일 미만이면 '자료 부족'.
### 계산 2 — 같은 계획 과거 재생
- 지난 250일 각 날짜에 "그날 종가 매수 + 같은 % 손절·목표" → 익절·손절·무승부 횟수(`broker.dry_outcome` 규칙 재사용 검토).
- 그날 **같은 신호**(⭐ 검증 순위 1~3 · 과매도 · 강한 유입 — setup3 판정)가 있던 날만 따로("같은 신호 N번 → 익절 a · 손절 b"). **컨닝 금지**(각 날짜는 그날까지 정보만).
### 계산 3 — 수량
- 주식 수 = 최대 손실 ÷ (매수가 − 손절가), 원→달러. 상한: 계좌의 10%(스승님 원칙) · 20일 평균 거래량의 1%(유동성). 걸리면 이유 표시.

## 4. 판정 문구(카드 배지와 같은 기준)
- 🪙 **거의 동전 던지기** — |익절% − 손절%| < 10%p 이고 기대값 ±1% 안 → "안 사는 것도 좋은 매매예요"
- 🟢 **유리한 편** — 익절% 뚜렷이 높고 기대값 +
- 🔴 **불리** — 반대 → "손절·목표를 다시 보거나 패스"
- 항상: "과거 움직임의 반복일 뿐 — 증자 공시·병합·실적 같은 사건은 반영 못 함". 카드에 희석 제외 사유가 있으면 빨간 경고 한 번 더.

### 8-4. 설계 바꿀 점 · 위험 · 작업량 · 질문
