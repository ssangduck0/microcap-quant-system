# 래빗스탁 차트 고수 관점 정리 — 키쟈키라 · ANO (2026-10-27 학습)

출처: 래빗스탁 커뮤니티 게시글 전부(키쟈키라 2,798건 · ANO 889건, 2026-04-10 ~ 10-27). 차트·수급 관련 글 1,225건을 읽고 반복되는 규칙만 추렸다.
목적: 우리 대시보드에 "차트 관점" 엔진·화면·신호로 옮기기 위한 설계 근거. (매수·매도 권유 아님)

## 1. 키쟈키라 — 급등주 눌림목 단타·단기 스윙 (차트쟁이)

### 1-1. 보는 순서(루틴)
1. **일봉**으로 전체 추세·지지/저항·기준봉을 먼저 본다.
2. **60분봉**으로 다음 상황(어느 구간이 막히나, 과거 거래가 빈번했던 구간)을 감지한다. 5분봉으로 작도하면 노이즈(개미털기·윗꼬리).
3. **5분봉**으로 진입 타점과 탈출 지점을 정한다. 1분·5분만 보면 전체 흐름이 안 보여 불안해진다.

### 1-2. 기준봉과 채널(오더블럭)
- **기준봉** = 가장 최근에 큰 거래를 동반한 급등 마디(장대양봉). 기준봉이 서면 그 구간이 기준가가 된다.
- 기준봉 **시작가 = 생명선(검정)**: 깨지면 상승 추세 사망. "휩쏘 제외, 거래를 동반해 깨면 아웃".
- 급등 마디를 위아래로 나눈 **채널**: 발(최저) → 무릎 → 허리(중간값, 빨강) → 어깨 → 머리(고점, 파랑) → **보라돌이**(오버슈팅·가장 강한 저항).
  - 채널 중앙선 위에서 놀면 매수 우위, 아래면 매도 우위. 머리를 강하게 돌파해 지지하면 "채널 이동"(윗 채널 열림). 반대도 같음.
  - 채널은 매수/매도가 싸우는 유동성 구간이지 "반드시 간다/지지한다"가 아니다.
- **허리(50% 되돌림)** 가 핵심: 허리를 지키면 추세 유지, 깨면 아래 채널로. "빠르게 오르면 빠르게 식는다(매물 공백)".
- 되돌림 단계(1파 고점 기준): ① −25~−38%(보통 −37% 부근이 1차 반등선) ② −40~−50% ③ −60~−80%(여기까지 오면 전고 회복 어려움). 과거 지지선과 겹치는 자리로 보정.
- 유형: A 어깨(목)에서 버팀 = 머리 +20% 이상 더 갈 확률 / B 허리(가슴)에서 버팀 = 쉬었다 머리 재도전 / C 무릎(엉덩이)에서 버팀 = 힘 없음, 어깨부터 처리.

### 1-3. 지지/저항·매물대
- 지지/저항 = **과거에 매수/매도가 싸운 흔적**(매물대가 진한 곳). 현재가 아니라 과거를 본다.
- **빈 구간(GAP, 공백)** 은 위로도 아래로도 빠르게 통과한다. "위에는 시체(매물)가 많고 아래는 뚫려 있으면 깨지는 순간 주르륵".
- 지지/저항은 **반복될수록 약해진다**(같은 구간 4차 지지는 리스크). 단, 3번 돌파 시도하면서 저점이 높아지면 4차 돌파 확률은 높다.
- **돌파는 크게**(타점 대비 +5~10% 이상) 나와야 되돌림에도 타점이 지지된다. 비비적대는 돌파는 좋지 않다.
- 저항 부근에서는 **그 구간의 과거 거래량을 소화**하는지 체크(예: 9/25 거래 터진 구간 소화 중).
- 쌍봉 자리 = 과거 직전 고점 = 누구나 탈출하고 싶은 자리 → "누가 그 매도를 받아먹을 상황인가"를 본다.
- 호가창: 타점(지지/저항) 자리에 매도벽이 세워진다. 시장가 매도 금지(얇은 호가는 연쇄 체결로 −10% 순삭).

### 1-4. 이동평균선(시간대별)
| 시간대 | 선 | 의미 |
|---|---|---|
| 일봉 | 5 / 20 | 5가 20을 골든크로스 = 급등 전조. 20일선 기울기 = 대추세(평평해지면 의심). 단기 추세는 5일선 위 유지 |
| 일봉 | 50(국장 60) | 세력이 주도해야 돌파하는 선. 100일선도 세력이 좋아하는 자리 |
| 일봉 | 200 · 1년선(≈250) | 큰 분기점. 1년선 돌파 지지 = 1년치 매물을 다 먹은 것, 크게 열림 |
| 주봉 | 5 / 20 | 주봉 5·20 골크 = 중장기 종목 |
| 60분봉 | 5 / 20 | 정배열 확장 단계 = 시세 확장. 5·20 라인 살아 있으면 추세 유지 |
| 60분봉 | 50 | 50선 타고 저점 높이며 우상향(잠복 자리) |
| 60분봉 | 200 | **돌파 지지가 나오면 공매가 똥줄 타는 구간 = 초기 파동 시작**(모든 급등주 공통). 뿅망치(저항)로도 작동 |
| 5분봉 | 5 / 20 | 급등 중 5일선 타고 가며 20일선에서 쉼. **5·20 둘 다 꺾이면 투매 신호**. 5일선(또는 20일선) 깨면 기계적 컷 |
| 5분봉 | 이평 수렴 | 힘이 모이는 중(위/아래는 수급·캔들로). 역배열→정배열 전환 시 시세 확장 |
| 5분봉 | 200 · VWAP | 당일 급등 후 2~3시간 뒤 5분 200선 근처 지지 → VWAP 까지 기술적 반등(~8%) = 당일 타점 |
| 1분봉 | 5 / 20 | 급등 시 1분 5일선 타고 20일선에서 쉼 |

### 1-5. 보조지표
- **파라볼릭 SAR(점도표)**: 캔들 위 = 매도 우위, 아래 = 매수 우위. 주가가 지지선에서 **횡보하면 점도표가 내려와 캔들과 만나는 "시점"을 미리 계산** → 그때쯤 파동 가능(일봉·60분·5분 각각). "점도표가 바뀐다고 바로 튀는 건 아니다 — 수급이 붙어야".
- 볼린저밴드 수축 + 점도표 접근 = 위/아래로 튈 준비(이때 수급을 본다). 일봉 밴드 상단 돌파 = 시세 확장.
- RSI 는 눌림목에서 "매도 힘의 변화"를 보는 보조.
- 체강(체결강도)·XL 매수 = 손바뀜·매집 흔적.

### 1-6. 거래량·세력 행동 모델
- 급등 후 급락하면 세력도 이탈이 어렵다(받쳐줄 개미가 없어서) → **물량 TEST**(짧은 펌핑 후 되돌림, 시작가는 안 깸) → **생명선을 의도적으로 지지** → 저점 매수 → 튀면 익절. (단타 패턴 1)
- 위에 시체(매물)가 많으면 세력은 돈 써서 안 올림. 내려서 투매 유발 후 싸게 흡수(호재 → 튐 → 시작가 아래로 꼬라박 → 매집 → 쌍봉 넘겨 급등).
- **시간은 세력의 무기**: 저점 횡보가 길어지면 개미 투매로 저점 갱신. 매집이 길수록 크게 가기도 함.
- 거래 동반 여부가 전부: 거래 없는 하락 = 추가 하락 의지 없음 / 거래 없는 상승 = 의지 없음. 하락 때보다 반등 때 거래가 적으면 매수세 약함.
- 에프터·기준봉·매집 흔적 없이 **데이장에서 갑자기 상한 가두리** = 거른다.
- 킷(LULD) 반복 중 상승폭이 줄면 의심. 텐버거·원버거(시작가×2)는 의미 있는 숫자라 이탈이 몰린다.
- 급등 중 패턴이 바뀌면(어제와 다른 시간대 덩어리 물량) 항상 의심.

### 1-7. 단타 6단계(원문 요약)
1. 당일 급상승 상위 종목에서 **눌림이 오는 것**을 고른다(거래가 터졌기에).
2. 일봉/60분봉으로 지지를 먼저 체크하고 피보나치 되돌림과 비교 검증.
3. **반드시 지지 자리에서 진입**(되돌림이 한 번 더 오는 쪽이 더 좋다). 타점 왔다고 바로 사지 말고 "내린 크기의 절반을 올리고 다시 내려와 버티는가".
4. 진입 전 5분봉 파라볼릭으로 매도 속도, 볼린저 수축 형태를 본다.
5. 지지 라인을 깨면 주저 없이 나온다(휩쏘 제외).
6. 반등 5%를 기본 목표, 10% 이상 튀면 무조건 익절. 단타 승률 구간 +5~50%.

### 1-8. 리스크 규칙
- 전체 시드의 20% 초과 금지(단타), 익절 +20% 미만 칼같이, 목표 달성·손실 시 그날 쉼(복수매매 금지), 잘 거면 팔고 자라, 시장가 매도 금지, 조건매도는 급락 시 건너뛴다.
- 불타기: 트리거 있고 수익 +50% 이상일 때 +25% 수익 수준까지만. 물타기: 트리거 확실 + −50% 이상에서만.
- 물장(돈이 안 도는 장)·나스닥 일봉 추세 이탈 땐 소액·휴식. 추세가 깨져도 종목이 죽는 건 아니다 — 대응이 원칙.

## 2. ANO — 차트 + 파생(옵션) + 공매도 + 거시경제 4축

### 2-1. 추세·이평
- **50/200 SMA**: 데드크로스 직전 = 장기 참여자까지 매도 시작(의미 있음). 200 SMA 지지(IWM 은 2년에 한 번) = 흔치 않은 매수 기회. SPY 가 200일선 위면 강세장.
- **이격도**: 50↔200 이 너무 멀고 200일선에 최대 매물대가 있으면(BNAI) 바닥을 만들기 어렵다. 주가 1/5 하락인데 매물대가 안 내려오는 건 비정상.
- 미국은 100일선 기준으로도 봄(강한 거래 동반 하락이면 안심 구간 아님). 50주선(50WMA)·200주선은 공매 최적기/최종 지지.
- 단기 손절 4/10 EMA(변동성 반영), 중장기 20/50/100/200 SMA. 초단타 타점 = 1분봉 200선, 3분봉 20/50선, 데이트레이드 추세 = 60분봉.
- 60분봉 볼린저(상단·중심·하단)로 추세/박스 판단. 밴드 워크, 수축 후 폭발, 3분/15분 하단 매수·상단 매도.

### 2-2. 패턴·캔들
- **수렴 돌파 + 이평선 관계**(TEM). 돌파 후 이평 저항에서 **윗꼬리 캔들 = 매도**(ASTS 대폭락).
- 고점 'ㅗ'(윗꼬리 긴 도지·역망치) = 모든 시간대에서 매도 승률 좋음. 긴 밑꼬리 = 매수.
- 상승 쐐기(신뢰도 높음), 폴링 웻지(거래량↓·ADX↓·2개월 이상·우하향 넷 다 맞아야), 컵앤핸들, 쌍바닥(저점은 기술적으로 2번 갱신해야 확정).
- **저점 추세 전환 비급**: 3~5거래일 연속 하락 + 각 하락일 시가가 전일 종가 아래 + 마지막 전일 시가를 넘을 때 매수(지수 편입주에 통함, 소형주는 안 통함).
- 15분봉: 양봉 몸통 고가가 직전 음봉 몸통 시작가를 넘어야 매수 승리. 음봉 3~5개 연속 뒤 직전 음봉 몸통 = 오더블럭 타점.
- 분봉 캔들 패턴은 눈속임이 많아 **다음 캔들에서** 매도 타이밍.

### 2-3. 거래량·다이버전스
- 주가↓ 거래량↓ **MACD↑ = 매도세 약화**(바닥 근접). 숨겨진 상승 다이버전스 + 하락 추세 = 물량 넘기기 6 : 상승 4.
- 주가 고저 평균↑인데 거래량↓ = 하락 다이버전스(RSI/MACD) — 여기서 사면 −10%.
- **유통주식 N배 회전**: ① 거래 돌려 수익 실현(상승 끝) ② 상·하단 매물대 밀집으로 지지 형성 — 4시간봉에서 이전 하락 거래량을 전부 먹으며 오르는지로 구분.
- 급락 뒤 반등 거래량 < 하락 거래량 + 원상 복귀 실패 = 눈치게임(최악). 바닥이려면 가격이 낮아질수록 거래량이 늘어야.
- **유동성 스윕**(로스컷 털기)은 V자 반등이 정상, 아니면 단순 하락. 매물 쌓고→하락 반복이면 그 매물대가 저항.
- 50일선 맞고 떨어지는 우하향 = 매집 or 저가 보유자 물량 넘기기 → 2개월 수평 횡보 후 거래 붙을 때 주목.
- MACD 8/17/9(변동 심한 주식), 5/34/8(1~3분 단타), 스토캐스틱 14/5/5(스윙), MFI.

### 2-4. 공매도
- 대차잔고 감소 = 숏 주문이 접수된 것(즉시 공매도 아님). 공매 평균가를 추정해 40~60% 수익 구간에서 단기 청산 반등을 본다.
- 공매는 50주선 아래가 최적기. 프리마켓에선 공매 안 한다(호가 얇음). 데이/프리는 참여자가 적어 ±10% 쉽게 → 정규장 매수.

### 2-5. 파생(옵션) — 지수·대형주 전용(소형주엔 옵션 없음)
- Put wall / Call wall, 감마 플립, 델타·감마 스퀴즈, Max pain, 0DTE, Charm, Vanna, NOPE, 핀 현상. 옵션 만기(지수 04:30·개별 05:00 KST), 위클리 VIX 만기(수요일), 옵션 개장 22:30.
- ※ 우리 대시보드엔 옵션 체인 데이터가 없다(유료). 이 축은 **보류**.

### 2-6. 거시 — "소형주 장세 ON/OFF"
- VIX 선물 18.5 ↑ = SPY 급락 전조, 20 ↑ = 스퀴즈 조건(만기 전 넘지 말아야), 하루 만에 30 ↑ = 폭락. VIX 콜 청산 = 진정. VIX 가 너무 낮으면(14) 급락 방어 장치 없음.
- 하이일드 스프레드 급증 = 단기 유동성 경색(포지션 크게 잡을 때 항상 참고). 2년물 금리 하락 + 증시 하락 = 주식 팔아 채권 매수 = 조정. 2Y/10Y 동시 하락 = 안정, 동시 상승 = 불안.
- **돈이 안 돌면 소형주는 종목이 안 나온다** → 쉬거나 소액.
- 세션 전략: 애프터 스켈핑 / 프리 자리잡기 / 데이 브레이크아웃 / 정규장 브레이크아웃. 장중 기회 2번(23~01시, 02~04시: 급등락 → 횡보 → 브레이크아웃).

### 2-7. 리스크
- 시드 30~40%만 운용(1,000 중 300), 3연속 손실이면 멈추고 복기, 수익금 30/20/50 분배, 손절은 게임이론(반복 게임에서 살아남기), 하루 1%면 연 200%.

## 3. 두 사람이 겹치는 공통 원칙(우선 적용 대상)
1. 지지/저항은 **과거 거래 흔적**(매물대)에서 찾고, 타점은 **지지 확인 후** 진입(바로 사지 않는다).
2. **다중 시간대**: 일봉(추세) → 60분봉(구간) → 5분봉(타점).
3. **거래량 동반** 여부가 돌파·이탈의 진위를 가른다.
4. 급등 후 **되돌림 깊이**(허리/−37%/−50%)로 다음 파동의 힘을 가늠.
5. **이평선 수렴 → 정배열 전환**이 시세 확장 신호, 꺾임(5분 5·20, 일봉 5일선)이 탈출 신호.
6. 윗꼬리 긴 캔들(고점) = 매도, 긴 밑꼬리 = 매수.
7. 시장(나스닥 추세·VIX·유동성)이 안 좋으면 소형주 매매를 줄인다.
8. 리스크: 시드 일부만, 목표 익절 기계적으로, 시장가 매도 금지.
