## 왜 중요한가(규정)
- **나스닥 Rule 5810(c)(3)(A)(iv)**(SEC 승인 2025-01 · 2025-01-30 시행): 최근 1년 안에 병합한 회사가 다시 $1 아래로 떨어지면 **180일 유예 없이 바로 상장폐지 결정**(청문 신청은 가능 — 패널 재량으로 추가 시간). 2년 안 누적 1:250↑ 병합도 유예 없음(예전부터).
- 즉 '병합 뒤 다시 $1 아래'는 곧 상폐 절차 위험. 학계: 병합 종목은 1년 뒤 비병합 대비 −15.6%(Klein·Rosenfeld) · 250일 안 시총 20% 회복은 24%.
- 래빗스탁: RS Scanner(예정·이력) 목록·푸시는 있으나 '다시 $1 아래 위험'은 안 보임(이전 조사).

## 덧붙임 — 더 나은 방법(같은 밤 · 사용자 '더 좋은 방법은?')
병합일 여유는 한 번 정해지면 안 바뀜 · 몇 달 뒤엔 여유가 이미 줄어 있음 · 같은 거리라도 변동성이 크면 쉽게 닿음(🎯 PICK 재생과 같은 이치) → **지금 가격 · 60일 변동성으로 '앞으로 120거래일 안 $1 아래' 를 매일 다시**.
- 병합 622건 × 병합 뒤 5·20·60·120거래일째(그날 실제 가격 $1↑ · 기간 다 지난 것) = 2,055 관측 · 120일 안 $1 아래 29%.

- 시간 분리(병합일 앞 절반으로 표 → 뒤 절반): 구간 ≤0.5 70 → 81% · 0.5~1 39 → 46% · 1~1.5 24 → 37% · 1.5~2 16 → 22% · 2~3 6 → 14% · 3↑ 1 → 0% — 순서 그대로, 최근 쪽이 5~13%p 더 나쁨(최근 자료로 자주 다시 만들어야).
- **상습 병합(직전 3년 병합 있음)은 같은 구간에서도 더 위험**: 1.5~2 27% vs 12% · 2~3 23% vs 4% → 표를 '거리÷변동성 × 상습 병합 여부' 로.

## 덧붙임 2 — 추가 검색 · 단서 확인(같은 밤 · 사용자 '혹시 모르잖아 더 좋은 방법이 있을지 추가로 검색')
**찾은 것**
- 학계: Neuhauser·Thompson(2016, 병합 1,206건 1995~2011) — 5년 안 47% 파산·상장 기준 미달, 11% 피인수 · **영업·주가 성과가 나쁘고 빚이 많고 병합 뒤 가격이 낮을수록 빨리 무너짐**. 병합 810건 연구 — **여러 번 병합한 회사는 65% 가 결국 청산·상폐**, 병합 뒤 수익률·유동성도 더 나쁨. Klein·Rosenfeld — 병합 뒤 1년 −15.6%.
- 실전·언론: Barron's — 병합은 흔히 **할인 증자·전환사채 발행과 같이 옴**(Bollinger 2022~ 8번 병합에도 12센트) · Warrior Trading — '병합 → 호재 → 증자' 반복 패턴.
- 국내: 2026-07 '동전주 상폐' 제도 뒤 병합 256건 · 병합 15곳 중 14곳 급락 · 평균 −31% · '병합보다 그 뒤 매출·수익성이 생존을 가름'.
- 병합 추적 사이트(Capedge · Briefing · Robinhood): 일정·이력 달력뿐, 병합 뒤 위험을 숫자로 보여 주는 곳은 못 찾음.

**우리 자료로 확인**(같은 2,055 관측 · SEC 공시 이력 150만 건 · 그날까지 낸 서류만)
| 단서 | 혼자 AUC | 있음 vs 없음(120일 안 $1 아래) |
|---|---|---|
| 병합 전 1년 조달 서류(424B·S-1·F-1·EFFECT·8-K 3.02) | 0.70 | 33% vs 9%(85% 가 있음) |
| 상습 병합(직전 3년) | 0.63 | 40% vs 20% |
| 병합 뒤 증자 서류 | 0.58 | 38% vs 24% · 같은 거리÷변동성 구간 0.5~1 에서 51% vs 34% |
| 병합 전 1년 상장 기준 미달 통지(8-K 3.01) | 0.50(무관) | |
- 앞 절반으로 맞추고 뒤 절반 AUC: 거리÷변동성 **0.817** → + 상습 병합 0.824 → + 병합 뒤 증자 0.825 → + 1년 조달·미달 통지 0.828 → + 병합 뒤 등락 0.833.
- → **거의 다 '지금 가격 ÷ 변동성'에 이미 들어 있음**(나머지를 다 더해도 +0.016). 확률은 '거리÷변동성 × 상습 병합' 표로 충분하고, 증자 서류·1년 조달 수는 **이유로 보여 주기**에 씀(학계·Barron's 가 짚은 경로라 사람이 판단할 때 쓸모).
- 학계의 '빚·영업 성과'는 과거 재무 시점 자료가 없어 재생 못 함 → 지금 런웨이(🪙)를 이유 줄에 같이.
