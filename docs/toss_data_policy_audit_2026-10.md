# 토스 Open API 데이터 이용 정책 점검 — 방문객 사이트 노출 목록과 선택지 (2026-10-29 밤)

읽기만 한 점검(코드 · 서버 DB 읽기 전용 · 토스 공식 FAQ). **코드는 바꾸지 않았음** — 아래 선택지 중 하나를 사용자가 고르면 구현.

## 1. 정책이 뭐라고 하나
출처: 토스증권 Open API 공식 FAQ 의 '데이터 이용 정책' 단락(`openapi.tossinvest.com/openapi-docs/faq.md`, 2026-10-29 23:40 읽음). 두 문장뿐이다.
| 문장 | 뜻 |
|---|---|
| API 로 받은 정보는 **투자자 본인의 매매 목적**에 한해 이용 | 내 매매를 위한 분석·알림은 괜찮음 |
| **상업적 이용 제외**, 비상업적이라도 **제3자에게 배포하는 행위는 엄격히 금지** | 돈을 안 받아도 남에게 '배포'하면 안 됨 |

- 벌칙 조항 없음. '웹사이트에 보여 주는 것'이 배포인지 직접 말하지 않음.
- 그래도 글자 그대로 읽으면: **토스에서 받은 숫자(순위·현재가·호가·체결·1분봉)를 다른 사람이 보는 화면에 그대로 내보내는 것은 '배포'로 읽힐 여지가 크다.** 우리가 계산한 점수·판정·신호는 회색 지대(원자료가 아니라 가공물), 그중에서도 '당일 현재가·등락률' 같은 숫자는 원자료에 가깝다.
- 참고: 야후 일봉(yfinance)도 약관은 개인 이용이다. 그래서 근본 해법은 "출처를 바꾸기"보다 **방문객에게 숫자를 덜 보여 주기**다.

## 4. 방문객 24화면을 세 등급으로
| 등급 | 화면 | 왜 |
|---|---|---|
| 🔴 토스 원자료 그대로 | 📈 급상승/급하락 · 🧲 수급 › 장마감 펌핑 체크리스트 탭 · 🌙 애프터 스캘핑 | 순위·현재가·호가·체결강도·1분봉 값이 화면에 숫자로 나옴 = 가장 명확한 '배포' |
| 🟡 토스로 계산한 값 + 당일 숫자 | 🏠 홈 · 🏁 종합 순위 · 🎯 PICK · ✅ 3대 조건 · 🏢 종목 · 🏆 검증 · 🧲 수급 › 매집 의심·세력·셋업 · 🏷 테마 | 점수·신호·판정은 우리 계산물(회색) · 같이 붙은 '현재가·등락률'은 원자료에 가까움 |
| 🟢 토스 무관 | 📖 가이드 · 🔔 공시 알림 · 📰 뉴스 · 💰 펀드스캔 · ⚡ EFFECT · 👤 내부자 · 📛 Reg SHO · 🧨 스퀴즈 · 🕶 다크풀 · 🔁 병합 · 🏦 대량 보유 · 🔬 이벤트 연구 · 📚 과거 사례 · 📅 공시 타임라인 | SEC·FINRA·ChartExchange·뉴스 피드. 현재가 칸이 있어도 야후 일봉 기준 |

주의: 🟡 의 '당일 숫자'는 스캐너가 토스 1분봉 우선, 없으면 야후로 계산한 값이라 종목·시각에 따라 섞여 있다(코드 `scanner.py` 1분봉 출처 로그 `토스 n / yfinance m`).

## 5. 선택지(승인 뒤 구현)
| 안 | 내용 | 남는 위험 | 공수 |
|---|---|---|---|
| **A. 원자료 화면 숨김 + 당일 숫자 가리기** | 방문객 서버에서 🔴 3곳 숨김(`HIDDEN_PAGES` 에 movers·after + 수급의 체크리스트 탭) **그리고** 🟡 화면의 현재가·등락률 열을 방문객에겐 '전일 종가(야후 일봉)'로 바꾸거나 숨김. 점수·신호·판정은 그대로 | 가장 낮음(남는 건 '가공물도 배포인가' 해석뿐) | 저녁 1회(화면 8곳 열 교체 + 테스트) |
| **B. 원자료 화면만 숨김** | 🔴 3곳만 숨김. 🟡 는 그대로 | 중간(당일 현재가·등락률 숫자가 남음) | 1~2시간(오늘 밤 가능) |
| C. 그대로 두고 동의문 강화 | 입장 동의문에 '개인 연구용 · 재배포 금지 · 토스 자료 포함' 명시, 초대는 소수 유지 | 정책 글자 그대로는 여전히 해당 | 30분 |
| D. 방문객 사이트 중단 | `quant-guest`·터널 끄기 | 없음 | 10분(사용자 서버 명령) |

**추천: B 를 먼저(오늘 밤), A 의 '당일 숫자 가리기'는 다음 저녁.** 이유: 정책의 핵심은 "받은 정보를 남에게 배포"이고 🔴 3곳이 그 자체다. 🟡 의 점수·신호는 우리 계산물이라 회색이지만, 당일 현재가 숫자까지 가리는 A 가 더 안전하므로 단계적으로 간다. C 는 위험을 줄이지 못하고, D 는 방문객 기능(가족·지인 공유)을 포기하는 것이라 마지막 수단.

## 6. 구현 메모(B 를 고르면)
- `access.HIDDEN_PAGES` 에 `"movers"`, `"after"` 추가(방문객 서버만 — 주인 화면은 그대로).
- 🧲 수급(`accum_ui.render`)의 '장마감 체크리스트' 탭: `access.is_guest()` 면 탭을 빼고 안내 한 줄.
- 🏷 테마 · 🏠 홈 브리핑이 급상승 순위를 인용하는 칸이 있으면 방문객에겐 '종목 이름만'.
- 테스트: `tests/test_access.py`(또는 test_nav)에 방문객 PAGES 에 movers·after 없음 · 수급 탭 수 · 주인 화면은 그대로.
- 가이드북 '👥 방문객' 문단에 "토스 자료 화면은 방문객에게 안 보임(정책)" 한 줄.
