## 수정 제안(재생 뒤 · 승인 대기) — '목표 종류별'(B′)
1. **baby shelf 목표**: 60거래일 도달 확률 10% 미만이면 '목표가 도달 범위 안' 탈락(2년 탈락 쪽 5.6% · 2026 4.4%). 지금 61개 중 baby shelf 21개 빠짐 → 40개.

3. **워런트·시총 목표**(과거 재생 자료 없음): 일반 표 확률을 '참고'로 표시만.
4. 확률을 `pick_signals` 에 기록(ALTER TABLE ADD COLUMN) → 🏆 에서 확률 구간별 실제 성공률(1월 중순부터) · 같은 상태 안에서는 확률 높은 순.
