# 🐷 ⑥ 규칙 검증 — 주식수 변동률 vs 이후 수익률 (2026-10-28)

## 결론
- 직전 분기보다 주식수가 **+20% 넘게 늘어난 종목(❌)은 보고서 제출 뒤 60거래일 수익률 중앙값 −16.0%, −30% 급락 터치 52%** 로, 20% 이내(✅ −5.4%, 35%)보다 뚜렷이 나쁘다(진입 당시 $5 미만 · 904종목 · 2만 316쌍 · 2016~2026).
- 반면 **+30% 급등 터치 비율은 ❌ 39.8% vs ✅ 37.3%** 로 차이가 없다 → ⑥ 은 저금통이 노리는 '발작' 기회를 줄이지 않고 급락만 거른다.
- 구간이 올라갈수록 단조롭게 나빠짐: ≤0% −1.9% / 0~10% −6.2% / 10~20% −10.1% / 20~50% −12.5% / 50~100% −13.8% / >100% −22.4%(60일 중앙값). **10~20% 도 이미 나쁜 편**(급락 44%) → '⚠️ 주의' 표시 후보(판정 기준 변경이라 승인 필요).
- 2024년 이후엔 차이가 더 크다(>100%: 중앙값 −30%, 급락 66%, 플러스 20%). '역분할 뒤 +100% 발행' 유형이 최악(중앙값 −32%, 급락 69%, 플러스 19%).
- 기준선 10%·20%·30% 모두 ✅/❌ 를 비슷하게 가른다 → 스승님 기준 **20% 유지**. 생존 편향(상장폐지 종목 빠짐) 때문에 실제 해악은 이보다 크다.
- 재현: `python docs/studies/yahoo_dl.py <폴더>`(universe_tickers.txt → yahoo_px.pkl) → 서버 `shares_hist` 를 CSV 로 → `python docs/studies/study_shares_change.py <폴더> <csv> [out.md]`. 테스트 `tests/test_study_shares_change.py`.

- 표지 36,317개 · 종목 1,426 → 분기 쌍 31,877개 · 종목 985 · 진입일 2016-10-28~2026-09-29
- 제외: 주가 없음 21종목 · 역분할 누락 의심(≤-50%) 426쌍 · 진입 뒤 20거래일 안 됨 43쌍 · 야후 가격 오류(60일 50배↑) 2쌍
